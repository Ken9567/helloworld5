# 3Dプリント工場タイクーン (Roblox)

3Dプリンターで小物を作って売り、お金を貯めて工場を大きくしていくタイクーンゲーム。
工場の建物はすべてスクリプトが自動で組み立てるので、Studio でパーツを置く作業は不要。

## 遊び方

1. ゲームに入ると空いている工場(最大4人分)が自動で割り当てられる
2. 緑に光る床パネル(購入ボタン)を踏むと、そのアイテムが買える
3. プリンターが造形物を作り、コンベアで「売り場」に運ばれるとコインが入る
4. 1つ買うと次のボタンが出てくる

| アイテム | 価格 | 効果 |
| --- | --- | --- |
| 3Dプリンター 1号機 | 無料 | 2秒ごとに 5 コインの造形物 |
| 3Dプリンター 2号機 | 100 | 2秒ごとに 8 コイン |
| 塗装ステーション | 250 | 通過した造形物の売値 ×2 |
| 3Dプリンター 3号機 | 400 | 2秒ごとに 12 コイン |
| 高速コンベア | 700 | コンベアが速くなる |
| 3Dプリンター 4号機 | 1,200 | 1.5秒ごとに 15 コイン |
| 検品ライン | 2,000 | 通過した造形物の売値 ×1.5 |
| 大型プリンター | 3,500 | 3秒ごとに 50 コイン(大きい造形物) |
| レジンプリンター | 7,000 | 2秒ごとに 70 コイン(半透明の造形物) |

価格や性能は `src/shared/Config.luau` を書き換えるだけで調整できる。

## Studio で動かす手順 (Rojo)

コードは [Rojo](https://rojo.space/) で Roblox Studio に同期する。

1. **Rojo をインストール**(どちらか)
   - VS Code を使う場合: 拡張機能「Rojo - Roblox Studio Sync」を入れる
   - ターミナルを使う場合: [Rokit](https://github.com/rojo-rbx/rokit) を入れてから、このフォルダで `rokit install`
2. **Studio に Rojo プラグインを入れる**: ターミナルで `rojo plugin install`(VS Code 拡張なら「Install Roblox Studio plugin」を実行)
3. **Studio で新しいプレースを作る**: テンプレートは「Baseplate」
4. **同期を開始**: このフォルダ(`roblox-tycoon/`)で `rojo serve` を実行
5. **Studio とつなぐ**: Studio の「プラグイン」タブ → Rojo → 「Connect」
6. **テストプレイ**: 「再生」ボタンで遊べる

## 保存について

コインと買ったアイテムは DataStore に保存される。Studio で保存を試すには:

1. プレースを Roblox に公開する(「ファイル」→「Roblox に公開」)
2. 「ゲーム設定」→「セキュリティ」→「API サービスへの Studio アクセスを有効にする」をオン

オフのままでも遊べる(保存されないだけ)。

## ファイル構成

```
src/
  shared/Config.luau          ゲームバランスの設定(価格・性能・倍率など)
  server/Main.server.luau     サーバーの入口。プレイヤーへの工場の割り当てと保存
  server/Tycoon.luau          工場1つ分の処理(購入・プリンター稼働・売上)
  server/PlotBuilder.luau     工場の建物をパーツで組み立てる
  server/SaveData.luau        DataStore の読み書き
  client/HUD.client.luau      画面上の所持金表示とお知らせ
```
